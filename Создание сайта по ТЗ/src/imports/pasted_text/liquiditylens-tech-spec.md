Техническое задание на разработку веб-платформы
Проект:
LiquidityLens
Тип продукта: SaaS-платформа предиктивного управления ликвидностью

1. Общая информация
Название проекта: LiquidityLens
 Формат: веб-сайт 
 Назначение: анализ банковских транзакций, прогноз ликвидности, раннее выявление кассовых разрывов, рекомендации по перераспределению средств между счетами.
 Целевая аудитория: treasury-команды, CFO, финансовые аналитики, операционные менеджеры, администраторы компании.

2. Цель проекта
Разработать веб-платформу, которая:
Подключается к банковским счетам через API или импорт файлов.
Собирает и анализирует историю транзакций.
Строит прогноз ликвидности на 7/14/30 дней.
Учитывает банковские праздники, выходные и задержки клиринга.
Выявляет риск кассового разрыва заранее.
Предлагает оптимальное перераспределение ликвидности.
Отображает всё это в удобном дашборде с понятной визуализацией и системой алертов.

3. Описание продукта
Платформа должна стать централизованным treasury-инструментом, который заменяет ручной контроль остатков и реактивное управление кассой.
Основной принцип продукта:
Не просто показывать текущие остатки, а предсказывать, где и когда появится дефицит, и сразу предлагать действие.

13. Бизнес-логика
13.1. Прогноз ликвидности
Система должна прогнозировать:
остаток по счетам;
риск дефицита;
ожидаемые пики и провалы;
влияние праздников и задержек.
13.2. Логика алертов
Алерт создается, если:
прогнозируемый баланс падает ниже допустимого порога;
ожидается задержка поступления;
обязательный платеж может не быть покрыт.
13.3. Логика оптимизации
Оптимизация должна:
минимизировать дефицит;
минимизировать idle cash;
снижать вероятность овердрафта;
не нарушать ограничения по счетам и валютам.

20. Краткая формулировка для команды разработки
Нужно создать SaaS-платформу для предиктивного управления ликвидностью, которая через банковские API и импорт транзакций строит прогноз кассовых разрывов, учитывает клиринговые задержки и праздники, показывает дашборд с рисками и дает пользователю возможность в один клик получить оптимальный план перераспределения средств между счетами.
